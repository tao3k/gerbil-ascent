* Scope

The ASCENT baseline is =3a5525376206ddea41ed91ed5a6dcd3374b3eab1=.
=build.ss= removes 43 lines of phase scheduling and compiler command construction.
The complete BuildSpec uses one standard build entry point.
SDK pins remain unchanged: Gerbil =1cfb032= and Gambit =ea114fc=, with SMP,
multiple VMs, and one thread per VM. No new SDK release or unpublished upstream
patch is required.

names. Upstream API names and original historical paths and SHAs remain intact.

Cancellation, resource limits, provenance, default Rayon, and alignment-only
dev-dependencies remain unchanged.

These controls do not establish the cause of the macOS result.

original 180-second deadline and is not accepted. That installation had not been
matched to the published archive SHA. Subsequent comparison found different
SHA256 values for =gxi=, =gsc=, and =gxtest=. A matching revision does not establish

original Release. Preserved process samples show

not establish the cause of the entire timeout.

An initial twelve-worker run on the original macOS Release also reached the
180-second deadline. A four-worker control then exposed a local rename omission:
one test still imported =../native/artifact-admission=. The import now uses
=../harness/artifact-admission=. Both corrected four- and twelve-worker runs
passed as recorded above. Earlier failures remain preserved. Host cold and warm
states were not matched, so these times do not establish parallel speedup.

The first wheel manually built from the repository root lacked source-identity

Python project directory with the complete CI features and release command
produced a wheel whose identity and interface matrix passed. The failed receipt
