* Assessment for the Library

The deployment-time layer must support more than Datalog.  A caller can
compare multiple model proposals; =gerbil-ascent= checks a relational
candidate where applicable, while another checker may execute code,
validate arithmetic or inspect a plan.  The common object is a bounded
attempt with inputs, observations, checker status and a next-step
choice.  A generated thought remains a model proposal.  It is never
promoted to a source fact or formal derivation by having a high score.
POO Flow, not the Ascent kernel, owns branching, scheduling and policy.

* Discriminator

Pair a graph reachability task, a small arithmetic task, and an open
planning task.  Each uses the same attempt/feedback envelope but a
different checker.  Compare outcomes, failed branches, budget use and
unsupported claims.  Do not infer that passing one checker certifies
all other reasoning domains.
