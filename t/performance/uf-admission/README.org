#+TITLE: UF closure admission and local reverse index retirement

* Production flow
=table/trrel-uf.ss= now dispatches an already reachable pair before predecessor
sorting and the predecessor/successor product. Both endpoints must already be
installed: a new reflexive node still requires budget and commit. Negative
budgets still reject even an empty frontier.

The insertion planning/commit branch is private =insert-components!=, receiving
one final =uf-insertion= record with its group, row and resolved endpoint owners. Budget
preflight remains read-only. Cyclic merging retires absorbed reverse keys before
clearing any component storage, preserving external predecessor and successor
keys of the winner. Complete transitive closure already contains all external
winner edges, so a local merge no longer rebuilds unrelated reverse adjacency.
The reverse-index activation path still performs its one initial rebuild.

* Gerbil source applied
SDK 1cfb032 =src/gerbil/runtime/table.ss:444-487= expresses table update/deletion
as explicit dispatch on key state, with a single mutation owner. Here admission
and commit are likewise separated by the existing graph invariant; identity
hash tables remain native. This is a private algorithm protocol rather than a
new public generic or inheritance hierarchy. No SDK build or runtime dependency
was introduced.

* Evidence contract
=reference.ss= is exactly =695ac3255d5a1896acd58eba65c93540195d59d1:table/trrel-uf.ss=
(blob =20cc0b50ac7190f95cb7dd200d34f48693163a74=). Both lanes use the same
static compilation, native process CPU and root allocation counters. Fifty
alternating pairs measure complete graph construction, insertion batches and
ordered frontier materialization. Every frontier is checked against an independent
incremental matrix closure outside timing; the frozen baseline supplies ordered
occurrence semantics. Benchmark contracts are generated with the public ASP
=make-benchmark-fixture= API and measured with =benchmark-run/result=.

Duplicate interior arcs, interior transitive arcs and local SCC merging require
at least 20% CPU reduction and 35 paired wins. New edges, endpoint transitive
facts, tiny and empty graphs are controls (110% plus 20us). Allocation budgets
are 110% plus 4096 bytes. This run launches no concurrent build or qualification
lane during timing. Global machine isolation is not asserted.

The first endpoint-only transitive experiment measured 3140 -> 3080us and failed
the initial 20% improvement gate (29/50 wins). Its raw receipt remains ignored
in =.cache/ascent/uf-admission/transitive-endpoint-failed.ss=. It shows that full
construction dominates a single-predecessor/successor query. The endpoint shape
is retained explicitly as a control, and a distinct interior transitive workload
exercises a nontrivial predecessor/successor product.
