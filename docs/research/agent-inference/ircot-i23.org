* Design assessment

The external Library does not modify model weights or its trained reward
model.  It supplies current, attributable observations at the turn where
the model needs them.  A Why-Not result can identify a missing premise;
a caller may turn that into a new search request.  The retrieved hit
returns as a *candidate* source observation, not an admitted fact merely
because it fills the gap.

* Discriminator

Use a two-hop question whose second search term is available only after
the first result.  Compare one-shot retrieval to a loop that receives
a typed missing-premise result and requests an exact source span.
Check answer evidence and unsupported claims as well as latency and
search/model calls.
