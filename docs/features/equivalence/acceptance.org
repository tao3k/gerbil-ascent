* Provider concretization active-domain eqrel concretization (2026-10-06)

The [[https://kmicinski.com/assets/byods.pdf][Provider concretization primary paper]] sections 3.1 and 3.3 motivate a representation-specific
closure/frontier instance, rather than assuming arbitrary Providers satisfy
Set semantics. =EquivalenceComponents= constructs active-domain reflexivity,
symmetry and transitivity after each injection, least closure after every
finite input sequence, exact newly emitted facts and isolated group updates.
The corresponding native suite checks exact per-insertion deltas against
independent Floyd closure, including rejected budget and retry on the actual
state. The [[file:../../evidence/scheme-eqrel-frontier-20261006/receipt.json][qualification receipt]] separates general algebra from bounded native
observations and lists the remaining representation extraction boundary.

This advances eqrel's semantic instance. General gamma/join/injection laws,
other non-Set/custom lattice instances, universal Scheme equality/component
extraction and native actor trace refinement remain distinct work. Existing
Quint publication/credit/failure models are unchanged; Lean owns these algebraic
laws. Published Provider concretization performance does not establish a Scheme speedup.


* UF root frontier proof progress (2026-10-07)

The [[file:../../scheme-trrel-uf-design.org][UF design]] now derives finite root-plan completeness from SCC equivalence,
root coverage and complete member lists. Candidate/frontier encoding is a
conclusion for that abstract construction. The SCC Quint publication model now
constructs emitted delta rather than assigning its oracle value, and admits
new endpoint activation explicitly. Three frontier mutations discriminate the
previous model's missing coverage. Native optimized remapping and grouped
encoding still require implementation correspondence; complete Provider concretization replication
and its application experiments remain governed by the matrix above.
