* Rejected observations and limits

The initial one-group 8192-tuple fixture produces a negative allocated-byte
difference (-130784) despite scalar result parity and lower CPU. Replacing the
direct helper with statistics slot 7 still yields a negative difference
(-130768); collecting slot 16 before/after also fails monotonicity (-130496).
These observations are rejected. The current SDK's wide recursive-call counter
behavior is not repaired by this production change, and the original wide
fixture does not pass allocation qualification. Its original contract is kept
in cache as =benchmark-wide.ss=. No negative count is clamped, offset, omitted
from an accepted sample or converted to a performance win.

The grouped fixture is a separately admitted workload with the same total row
count and numeric gates, not a repair of that wide fixture. A first source build
also rejects the missing =lambda-match= import; the explicit pinned support
import resolves it. All failed builds/observations, final logs, receipts and
binaries stay under ignored =.cache/ascent/aggregate-input=. Root =build.ss=
is unchanged; no SDK rebuild or new environment switch is introduced.
