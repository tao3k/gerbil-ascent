#+title: ASCENT library boundary
#+language: en

* Public library

ASCENT is a reusable relational and logical programming library. It owns
checked rule declarations, query admission, fixed-point execution, retained
sessions, incremental updates and generic derivation provenance. A result
and its witnesses are bound to the admitted rules and source generation.
Consumers own source selection, external authority, application policy and
effect authorization.

* Entry points

Scheme clients import =:gerbil-ascent/program/api= for the checked DSL and
session operations. For trusted Scheme rule modules, the declaration entry
is =define-program=. Python clients use =Engine.rules= for rule modules and
=Engine.dsl= for DSL source. See [[file:../README.md][the native example]]
and [[file:../python/README.org][the Python bindings]].

* Agentic AI Lab integration example

[[https://github.com/tao3k/agentic-ai-lab][Agentic AI Lab]] is one downstream
library. Its development branch declares ASCENT as a dependency and exposes
its temporal integration through =TemporalCausality=. The published operations
include =ascent-exchange-solve= and =ascent-exchange-verify=. The Lab also
maintains its own evidence-assessment interface.

These interfaces were checked against [[https://github.com/tao3k/agentic-ai-lab/pull/34][Lab PR #34]]
at =4954eb8a=. The linked package manifest pins the ASCENT revision used by
that integration. Follow the Lab's own selected revision when using those
operations.

* Qualification

Run the native Scheme, Rust/PyO3 and formal checks for the ASCENT producer.
Each downstream library qualifies its own consumer configuration with its
resolved dependency versions. Historical package names and import paths in the
[[file:migration-audit-20261021.org][migration audit]] identify the original
experiments.
