#+TITLE: Concrete incoming endpoints for cold SCC splits

* Source and proof

The existing incoming quotient mask tells which components have a
cross edge into the selected SCC. It cannot distinguish two edges from
the same predecessor that land in different vertices of that SCC.
The source view has no target-bound index, and the edit journal indexes
changes only. Reusing either alone would lose the new target owner.

The already-required cold quotient scan captures the concrete cross
edges in buckets keyed by the existing destination component ordinal.
A bucket is complete or is unavailable. Capture stores at most as many
edges as vertices for the entire index. A split with a complete bucket
translates the retained direct masks, then visits the selected bucket
and adds the new target bits for the retained source owners. The
fallback scans the original rows whenever the certificate is absent or
the edit is metered. An internal edit preserving membership can retain
the buckets. A changed cross edge or repartition discards them, and an
exact merge inverse restores the saved payload. Result witness closures
carry no copy of this worker-only index.

=retained_incoming_projection_exact= proves that a bucket supplies exactly
the cross bits that the retained predecessor scan would supply. The
raw coordinates remain valid while the concrete graph and old owner
map match the payload. =internal_removal_preserves_incoming= justifies
sharing across an internal edge removal. =packed_cross_endpoints=
connects the packed representation to the concrete endpoints. The
existing closure, owner checkpoints and ordered witness adjacency
remain the sources of reachability and publication semantics.

The temporary min/max arrays of the packed SCC walk use the extent of
the selected vertices, through =selected_boundary_offset=. Observed
arrows are one list of packed endpoint pairs. Certified rows can skip
their internal intervals. Uncertified rows still read their adjacency.
Projecting an already seen fallback edge again is idempotent, using
=repeated_quotient_target_exact=. This eliminates the extra full-graph
array of per-row capture lists. Caps and publication checks are unchanged.

improvement.

SCC summary and independent oracle suites passed. The complete guarded

complete-list failures remain in their preceding reports. The recursive
