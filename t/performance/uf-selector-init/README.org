* Scope and source learning

This batch freezes =0d2b6ed:core/relation-view.ss= as an independent reference.
It follows the compact-query batch with the same complete consumer inputs,
not a comparison against its older pre-optimization baseline. The engine
changes from other sessions remain intact; only the frozen query owner changes.

Gerbil SDK =1cfb032/src/gerbil/core/sugar.ss:933-981= uses scoped syntax to own
admission bindings and their lexical continuation. =src/std/list/list-builder.ss=
constructs its output spine within the consumer extent. The implementation
applies those patterns to the entire checked query flow:

- A private =walk= rule expands binary/group coordinate literals into =case=.
  Normal coordinates no longer invoke dynamic arithmetic comparators per repeat.
- A paired column/key cursor admits lengths, column syntax, range and repeated
  values while retaining the first key tail, including a fixed =#f=.
- Proper-list prechecks still reject improper or cyclic inputs. Syntax rejection
  precedes range rejection; a conflict does not hide a later invalid column.
  No result collector is constructed before compact admission succeeds.
- Materialization, row streaming and checked parts use that shared admission.
  Complete points, tiny cuts, mixed schemas and scans retain their checked paths.
- When both endpoints are bound, the parts callback publishes the selected
  stored scalars directly. It does not re-enter two singleton Cartesian walkers.
  Partial endpoint queries retain product traversal and captured ordinal order.

No retained query cache, mutable shared cursor, new environment switch or SDK
rebuild is introduced.

* Build supervision repair

The two historical 120-second failures above were caused by a wall-clock
=timeout= around optimized compilation, not demonstrated compiler deadlocks.
The build retains O3, the full module inventory and native machine concurrency.
The existing Python supervisor now owns compilation activity; no timeout value
is increased. Its five-second no-output/no-CPU check rejects a genuine stall,
while real work can continue past the old wall-clock cutoff. Each native A/B
measurement still has its original independent 90-second runtime limit.

Darwin =ps= sampling failed the short-lived-child control: exited/reaped compiler
CPU was missing. Public =proc_pid_rusage(RUSAGE_INFO_V1)= supplies user/system
and child CPU nanoseconds instead. Linux reads the corresponding =/proc= tick
counters. Group totals avoid treating a child-to-parent accounting transfer as
new work. Eleven supervisor regressions cover continuous work beyond the idle
window, sleeping processes, reaped children, closed pipes, orphan cleanup,
output preservation and failure propagation. The rejected =ps= attempt remains
recorded separately. No Gerbil/Gambit source was rebuilt.

The complete 563-module preparation now exits zero, with production-rebuilt=0
and full before/after source admission. The first successful local preparation
