* Design consequence
:PROPERTIES:
:CUSTOM_ID: dbsp-local-transfer
:END:

The existing =program/session.ss= already retains the admitted rule
engine, source snapshots and indexes. The local
[[file:e4-retained-session.org][retained operator experiment]] uses that owner for a first-class Scheme
transformer, then records a separate fresh-materialization control.
The finite =relational-op-delta-change= interpreter remains a semantic
comparison; it does not acquire DBSP's proof or persistent state by
renaming its old/new row sets.

A meaningful improvement claim needs paired update sequences,
including initial materialization and retained memory, plus complete
result equality and an explicit supported grammar. The local probe now
includes one chain sequence with initial materialization and eleven
insertions, but does not measure memory and has noisy local timing.
Source replacement recomputes rather than applying signed changes.

* Falsifier
:PROPERTIES:
:CUSTOM_ID: dbsp-falsifier
:END:

If a retained update returns a different complete set from an
independent finite closure, or if a failed update changes the last
completed snapshot, the local Session integration fails its semantic
gate regardless of timing. If matched lifecycle cost is not lower on a
target workload, retain the semantic API without a performance claim.
