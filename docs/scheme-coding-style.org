#+title: Scheme Coding Style

* Purpose

Study the installed Gerbil compiler and standard-library Scheme sources, and
apply their organization, binding, representation and state-ownership patterns
to ASCENT. Each topic records concrete source references, implemented changes,
semantic gates and rejected candidates. This index is the entry point; new
studies belong in the corresponding topic file.

* Reading order

1. Architecture and responsibility: current ownership and dependency direction.
2. Compiler and Scheme patterns: upstream techniques and local applications.
3. Planning, storage, Sessions and evidence: the affected production chain.
4. Build/test boundaries, rejected experiments and qualification history:
   evidence for each study, with its original budgets and revision boundary.

* Evidence policy

Historical receipts apply to their recorded revision. Local semantic tests,
matched performance results, AOT application checks and remote CI are separate
claims. Generated logs and experiments belong in ignored =.cache/=. This
collection stores the reasoning and receipt boundaries, not execution logs.
