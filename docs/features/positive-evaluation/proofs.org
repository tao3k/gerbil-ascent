* Positive SCC semantic closure

[[file:../../../packages/proofs/lean/ComponentClosure.lean][ComponentClosure]] closes the semantic component-decomposition obligation for
ground positive Set rules: local stability implies closure, owned writes preserve
unrelated facts, no backward reads preserve earlier closures, and complete
stable topological plans compute the least model. Independent component orders
agree. Unlike the TLA+ task inventory, this proof contains no mailbox, credit,
worker or publication state. No generation or iteration upper bound is imposed.

The [[file:../../evidence/scheme-component-closure-20261006/receipt.json][receipt]] distinguishes this universal ground-rule theorem from the native
recursive-diamond qualifier and the existing finite ready/credit protocol.
The original conditional theorem is retained. =local_stabilizes= now derives
local stabilization from finite ground rule-head rank, including duplicate
heads and arbitrary seeds. =planned_stable= supplies every component witness;
=topological_least= consequently needs only complete head coverage and sound
topological dependency ownership. Its =n <= rules.length= is a derived theorem,
not a native round limit; the witness plan is noncomputable semantic evidence.
See [[file:../../evidence/scheme-component-termination-20261006/receipt.json][follow-up receipt]]. Native binder/row encoding, SCC/head
projection, asynchronous refinement and general non-ground/lattice termination
remain required for whole-engine closure.

=GroundedBinding= now constructs finite ground clauses from successful ordinary
binder paths, rather than assuming a consequence certificate. Universal
=ground_exact=, =compiled_ground_exact=, =program_exact= and =closed_exact=

See [[file:../../evidence/scheme-binder-grounding-20261006/receipt.json][qualification receipt]].


* Relation projection and native SCC qualification

=ComponentProjection.reads_exact= proves that ground fact reads project exactly
to direct relation read edges. =depends_exact= then transports relation ownership
to component dependencies; =topological_of_projection= derives the ground
closure order premise from no backward projected edges and a unique order.
The native 512-graph qualifier uses independent Floyd reachability to inspect
SCC equivalence, total unique ownership, immediate predecessors, topological
IDs and preserved projected head count. This closes the semantic projection
contract and strengthens bounded native correspondence evidence. It is not a
universal native Tarjan proof, nor a temporal scheduler proof. TLA+ models stay
unchanged and retain ready/credit protocol ownership. See [[file:../../evidence/scheme-component-projection-20261006/receipt.json][source-bound receipt]].
