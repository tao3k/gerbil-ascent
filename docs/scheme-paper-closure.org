每项只有在以下证据均匹配时才能收口：
1. 论文定位、接受的 Scheme 行为和实现 owner 明确。
2. 独立真值、Rust 差分或明确记录的上游差异覆盖该项及其交互。
3. Lean/TLA+ 证明命题与实际实现之间有明确对应；尚需假设不能当作结论。
4. 正负对照、失败/超时行为和资源约束均有当前源码绑定的执行结果。
5. 该项声称的性能收益有同输入、同语义、交替顺序的测量；负结果保留。
6. 最终 GitHub 提交的 CI 和消费者 pin 验证通过。

旧快照相同；真实 owner 已接收 credit 批次，所以不能直接将该前提移到

* Positive body / frontier 联合推进（2026-10-05）

重新读取 B23 §3.2，尤其 Lemma 3.2–3.4 / Theorem 3.5（pp.8–9）。
论文把单步分解、旧事实已经被推导的历史条件、抽象数据结构的 gamma
契约和迭代等价分开。当前实现也必须保留这四个环节。

本轮 [[file:evidence/scheme-body-frontier-20261005/receipt.json][联合验收回执]] 对应三个职责：

- Lean =ProviderFrontier.body_partition= 对任意长度的有限正向 body 证明
  full = old ∪ single-delta pivots；环境传递允许共享变量和重复 relation key。
  =projected_partition= / =projected_frontier= 证明任意纯 head projection
  下的结果和精确输出 delta。Pivots 可以重叠；新 witness 不等于新 head。
- =new_consequence_pivot= 明确要求 all-old heads 已包含在 known database，
  才能省略 all-old body。这是待由迭代历史建立的前提，不能用 Provider
  frontier 完整性替代。空 body 保留 seed；初始全量执行仍不可省略。
- TLA+ =ProviderFrontier= 检查 private pending frontier 到 committed total
  的消费顺序及三 atom 下游 publication。=ConsumerSnapshot= 在 pending
  和 idle 都成立；提前发布和消费旧 total 的 mutation 必须失败。
- Scheme 原生 Suite 为 eqrel / trrel / trrel-uf 枚举 27 种三边输入与
  producer 分区，共 81 个完整程序；relay 延迟第二 producer，三次读取
  同一个 closure relation 并共享变量。结果与独立图闭包、三边 witness
  枚举比对，不以另一个相同 evaluator 作为真值。

这是正向 concrete body 的单步语义链；尚未证明一般 lattice、negation、
aggregate 或任意 host callback 的 delta 分解，也没有 native extraction。

* Concrete positive Set iteration history（2026-10-06）

[[file:../packages/proofs/lean/SemiNaive.lean][SemiNaive]] 将上一轮的规则体分解提升到有限规则集合的完整同步迭代：

1. =consequences_partition= 证明所有规则输出的 full/old/pivot 分解。
2. =pivot_after_full= 从上一轮 fullStep 的定义推导 all-old heads 已被纳入，
   不再要求 caller 给出 covered 前提，也不要求求解已 completed。
3. =iterations_equal= 对所有 Nat 轮次证明 semiNaive 连续两个 snapshot
   与 naive 的对应轮次相等。初始轮必须 fullStep；空 body 事实不会被遗漏。

精确范围：数据库是具体 Set，规则有限，body 是有限正向环境 transition，
head projection 纯且固定，view 在 Set inclusion 下单调；delta 是相邻
concrete view 的精确差。重复 key / 共享变量沿用 ProviderFrontier 的语义。
规则集合允许为空，规则 body 允许为空，轮次无上限。

它没有假定原生结果成功，也没有添加终止假设。全轮次一致不能单独推出
有限轮次收敛；终止仍需 FiniteHeight 的有限高度/进展及 descriptor 对应。
B23 一般抽象 lattice 的 join、gamma/injection 和 gamma-total/delta 契约
仍需独立连接；本轮定理没有把任意 caller Provider 视为满足这些契约。

TLA+ 保留协议职责：ProviderFrontier 同时检查空初始 cut 和有种子初始 cut，
并拒绝仅运行 pivot 而漏掉初始完整 consumer 发布的 mutation。该有限安全
检查不是 Lean 全迭代代数的替代，也不是无界 temporal theorem。
