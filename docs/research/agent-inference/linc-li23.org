* Assessment for the Library

The key distinction is between =the proposed program is well formed=
and =the proposed program means what the source says=.  The Library
can prove neither natural-language equivalence nor source authority.
It can expose the exact rule/tuple it executed, binding modes and
complete output, so an Agent or independent reviewer can challenge
the formalization.  Source spans and generation identifiers remain
caller-owned evidence, not facts invented by the solver.

* Experiment

Pair one ambiguous sentence with two syntactically valid but
semantically different rules.  Both should run.  The response should
show their different complete results and the proposed source span,
without labeling either as the intended interpretation.  An Agent
must ask for more evidence or select an interpretation explicitly.
