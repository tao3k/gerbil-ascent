** Ordered consumers and cost repair

The total journal exporter retains public legacy order. Internal evaluator roots
are its reverse. Bound delta exporters instead reproduce legacy pending order:
source and derived injections both prepend frontier occurrences. Replaying a
delta reconstructs earlier injections without expanding their old pairs; the
cut must fall at an injection boundary. Total export streams source frontiers
directly, eliminating the temporary source batch and its extra list reversal.
Derived batches retain their required orientation. Replay still allocates a UF
owner and exported pairs; remaining regressions must remain in the new receipt.

Ordered consumers own an explicit expansion cache per captured total/delta cut.
This cache is allocated only for programs with observable callbacks, custom
receivers, field checks or lattice joins. A changed cut replaces its cache entry.
Pure canonical programs retain compressed access, including worker execution.
Thus pair-retention avoidance applies to that pure path; callback compatibility
has a separately documented expansion cost. Nested host values still require
the existing stability contract.

** One implementation and research chain

instance of that history requirement. It does not generalize that contract to
arbitrary lattice concretizations. The paper was reread for this integration.

** Plan-selected routing and native differential entry

The first eager-routing native cut passed 800 Cases but raised sparse DAG
allocation above the explicit path. The engine now admits sources with an
unindexed frozen carrier, inspects the already validated atom plans afterwards,
and activates total routing for bound variable keys. Fixed literal keys retain
filtering without routing construction. Routed source totals are recaptured
with unchanged identity, revision and logical cardinality; future publications
use the same per-relation decision. Callback programs retain ordered expansion.
Source diagnostics still precede rule planning. Construction and recapture costs
remain inside the matched whole-engine measurement.

Five-second runtime controls rejected both parallel and serial interpreter
startup for the old differential recipe. EQREL/TRREL/UF and grouped-query
fixtures now enter the existing native DSL closure with the same stdin and row
protocol. The native entry runs the existing artifact admission checker before
reading fixture input; its verification marker goes to stderr so row stdout
remains unchanged. Admission checks the current source/recipe hashes before
execution. Every oracle shard builds that closure; =just oracle= owns its build
prerequisite. The independent =check-source-views= gate continues to exercise
source loading. Rust preserves exact stdout bytes while reporting actual reads
and completed eight-node cuts; CI uses =--nocapture= and serial BYODS execution.
Oracle recipes supervise stdout and stderr separately: diagnostics count as
actual output without entering the row protocol. Six transport glue tests cover
binary bytes, stderr progress, stalled children, CPU build progress and failure
propagation. No synthetic heartbeat or
runtime timeout widening qualifies this path.

** Local SCC adjacency for the scale progress gate

The five-second runtime gate exposed whole-root scanning in every UF insertion
on the 10,000-edge disconnected-component fixture. Groups retain the legacy
scan through 64 roots; after successful preflight a larger group installs a
private inverse reach map. Predecessor/successor candidates then come from local
closure maps and are ordered by stable root creation ordinals, matching the
legacy prepended scan. SCC merges rebuild inverse maps from canonical surviving
reach keys. Failed admission does not activate routing or mutate graph state.
The new ordered-frontier Case compares every insertion with the frozen
=c131042= UF kernel across activation, partial SCC unions, external bridges,
grouped keys and zero-budget rejection; held frozen cuts remain stable. This
is an implementation discriminator, not a new extracted adjacency theorem.

The first four-process full native run stopped at the existing opaque
64-graph reasoning Case. It now reports each completed eight-graph group only
after both receipt-status and independent closure assertions succeed. This
retains the same 64 masks and five-second deadline; the rejected run is excluded
from the final acceptance receipt.

The latest =e406584= provider audit is retained. The private reverse maps and
root ordinals now enter its explicit validator as well: root-list order,
complete inverse edges, no stale predecessor keys and absorbed-map release
are checked after successful and rejected admission in the large-root control.
This validator remains outside insertion and query hot paths. Rejection checks
compare logical snapshot content and physical counts; independently captured
hash traversal order is not a mutation contract. Ordered frontiers, journal
replay and held-cut traversal retain their exact sequence controls.

Grouped decoding and journal correspondence now include
=ProviderEncoding.root_plan_encoded_exact=, =scopes_disjoint= and
=orient_member/count/nodup=, plus the six =ProviderReplay= mutation controls.
The local replay gate retains the original TLC checker/model/bounds and reads
its generated-state counter once per second; it emits a marker only when that
counter increases. An unchanged counter provides no progress marker. The
qualifier source is retained with the runtime evidence for reproducibility.
