#+DATE: 2026-09-26

* Scope and reading rule

This matrix collects the papers already used in the gerbil-ascent and MRR
research programs, plus the published Soufflé and differential-dataflow
baselines needed to compare physical plans and concurrent updates.  A paper's
result is a hypothesis or an independent baseline for this project until a
named fixture and benchmark reproduce the relevant property.  The [[file:rust-parity.org][Rust
Ascent parity contract]] remains the completion gate for the Scheme kernel.

The =gerbil-ascent= column describes executable mechanism or missing evidence.
The MRR/Agent column describes a downstream research question, not a transfer
of source identity, admission, authorization, or effect ownership to the
evaluator.  A model score is a judgment over supplied state, not a derivation
or permission to act.

* Priority and ownership

1. Complete A22/B23 behavioral parity before promoting a new Agent extension.
   Use the Rust oracle for behavior and the standard SS scenarios for cost.
2. Use D13/D23/H18 to compare retained updates with full recomputation after
   every insertion and deletion.  Equality includes the fact set and MRR's
   required supports for the same generation; an update-cost claim also needs
   a cold/warm workload receipt.
3. Use F16 to specify which user-supplied procedures and lattice joins can be
   admitted safely.  E23 and F20 are separate optional extensions, each with
   its own equivalence or constraint oracle.
4. Keep P07/P22 provenance semantics in MRR.  gerbil-ascent may emit bounded
   candidate evidence, but it cannot assign source authority or select the
   meaning of an admitted explanation.

The first Agent-facing comparisons use frozen coding-Agent, incident-triage,
and research-Agent fixtures from the [[https://github.com/tao3k/meta-relational-reasoning/blob/research/ascent-poo-flow/research/ascent-poo-flow-research-program.org][MRR research program]].  Under the same
source snapshot, action set and budget, compare retrieval plus model judgment
with retrieval plus admitted MRR derivations plus judgment.  Measure affected
fact recall, unsupported action rate, explanation fidelity, abstention,
end-to-end outcome, latency, memory and cost.  The decision model is a
consumer of admitted evidence, not the oracle for it.
