#+title: Equivalence injection admission and keyed traversal

* Gerbil source and production flow

Gerbil =1cfb032= =compiler/optimize-call.ss:390-415= resolves constructor class
metadata and method implementation before emitting the call expression. It uses
=using= for class values whose provenance is established. The transferable
pattern is to prepare a local selection once, then let the writer consume it.
This supplies expression discipline, not ASCENT's equivalence semantics.

=table/eqrel.ss= now compiles checked column/key constraints into private final
=coordinate-key= records. False is a normal bound value. Conflicting repeated
constraints select nothing. Selected members retain the original stored value
rather than the caller's equal query object. For each left member, forward and
backward eligibility choose the necessary right spine. When both orientations
apply, their union retains original right-member order. Each visited pair still
emits forward before backward, and diagonals still precede cross pairs.

Only matching rows are constructed. Prefix mismatch stops traversal before any
Cartesian rows. Full export keeps the direct writer without query records.
Insertion budgets, weighted component merge, count-only staging and frozen
publication remain under their existing owners. No new runtime configuration,
Provider capability, dependency or environment variable is introduced.

heap. Sampling processes run alone. Component preparation, total freezing and
whole solver execution are outside timing.

The qualifier runs eqrel-view, provider-view and relation-view Suites. Final
=OK=, successful Case statuses and exit zero are required. A new unit Case
compares keyed injection output against the independent eager provider through
successive merges, repeated/reordered keys, group/false values, held frontiers
and original string identity. Logs, binaries and raw paired receipts stay in
ignored =.cache/ascent/eqrel-selection/=.
