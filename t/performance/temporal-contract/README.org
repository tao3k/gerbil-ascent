* Matched complete construction

ASP Scheme benchmark API executes 50 alternating old/new pairs. Each invocation
constructs both a lens and a source twice, including admission, uniqueness,
canonical sorting, inert capture and detached projection. Every timed and
allocation invocation must match the frozen constructor and independently
prepared canonical coordinates. Fixtures use ids n1000..n1255 and distinct
source-first parent pairs. Input preparation is outside timing.

Predeclared targets require <=90% median CPU and at least 40 faster pairs.
Small/empty controls allow 110% +20 us. Allocation allows 110% +4096 bytes.
CPU is process user/system time; a separate semantically equal invocation
between forced GCs measures VM allocation via statistics slot 16. Each
allocation difference must be nonnegative; forced GCs are outside CPU timing.

* Qualification and reproduction

Build =build.ss <absolute .gerbil/lib> <absolute binary>= for the constructor
runner; third argument =qualify= builds the native std/test runner. Run pairs
sequentially for =wide medium small empty=, with a separate receipt path.
Logs, failed invocations and receipts remain under ignored
=.cache/ascent/temporal-contract/=; no benchmark logs are committed.

The semantic suites cover all three-node directed graphs, roots and horizons
against an independent shortest-distance model and the frozen original solver;
canonical interval windows, supplied callbacks, frontier order, source
ownership, native evidence replay, hypothetical forks and comparisons remain
part of qualification. New constructor cases check independent canonical
coordinates, duplicate symbols/structural parent pairs, interval callback
schedules and detached input/output spines.

Final qualification covers 3 suites and 19 cases. Targeted temporal source policy
reports one advisory about repeated match bodies in uniqueness admission and
zero errors; this is not a warning-free claim. Final paired receipts use
=*-final-receipt.ss=. The first paired run is retained alongside them.

The final rebuilt native harness exits zero with every =CASE-OK= and final =OK=.
Direct source loading also completes solve and =temporal-verify= on the public
facade and emits =SOURCE-TEMPORAL-OK=. The constructor gains and solver semantic
checks are separate receipts; no whole-solve timing improvement is claimed.
