* Goals and implemented changes

Assess the entire task until BOTH query obligations first pass independent grading, including all failed attempts and repairs. Distinguish anticipation of failure from actual repair after a failure. Report censored controls and negative results without assigning an invented first-correct cost.

The previous taint increase of 746 thinking tokens came from +1,038 on an identical initial prompt before native exposure, offset by -292 after exposure. Shared initial responses now control that sampling difference: both alternative policies charge the initial usage fully, while physical expenditure counts the request once. Shared-prefix control is not a runtime optimization.

Runtime changes are a source-bound intermediate projection API and explicit task/subgoal verification scope. EvidenceChain.intermediates refuses final answers, unknown components, duplicate names and stale references, and retrieves actual native rows. Native Trajectory cannot freeze task cost at subgoal success. Lean proves that boundary, Quint includes a premature-admission counterexample, and both compiled bindings exercise it.

* Corpus and scientific scope

Eight independent task instances have two query obligations each, with unchanged sources and different final-query rules. Four diagnostic cases retain ordinal job labels and are exploratory. Four subsequent independent held-out cases use opaque randomly assigned identifiers that do not encode construction order or class. All sixteen query obligations agreed between independent Python fixed-point oracles and actual Scheme before paid calls. Satisfiable/unsatisfied candidates are mixed to avoid all-negative cases. The holdout cohort was frozen before its first model request.

Tagged taint tasks use four tag-local domains, conversions and mutually recursive flow/permit state. Balanced-path tasks require matching labels, concatenation, epsilon and context-local denied edges. State spaces reach four contexts over 32 nodes, with 160 requested classifications and over 1,800 completed intermediate rows. Complexity comes from recursive joins and tuple scopes, not node count alone.

Task design is informed by [[https://doi.org/10.1145/199448.199462][precise interprocedural dataflow via graph reachability]] and [[https://arxiv.org/abs/2609.37233][DatalogBench]] execution/mutation methodology; feedback across attempts follows the motivation of [[https://arxiv.org/abs/2303.11366][Reflexion]]. These are generated tasks, not official benchmark scores, full IFDS implementations, or proof of training exclusion. Underlying algorithms may be familiar to the model.

Because these inputs provide complete executable relational programs, an engine-only evaluator is sufficient to compute the answers. This study measures avoided redundant model evaluation and evidence-assisted composition; it does not establish that an LLM is necessary for these tasks or demonstrate generalized natural-language problem solving. No engine-only performance comparison or total-dollar saving is claimed. Provider latency is retained per request; total end-to-end engine latency and dollar billing are not a qualified outcome of this study.

* Protocol and whole-task metrics

One actual initial model response is shared per paired task. Both conditions preserve completed reasoning/message output opaquely, alternate continuation order, use high reasoning and the same 131072 output cap, and allow at most three attempts per query. The treatment receives only completed flow/permit or balanced facts. No final job-answer relation is supplied. The primary endpoint charges every preceding call, including the shared initial call. Subgoal successes cannot end it.

Incomplete output-budget responses in the holdout protocol count as failed attempts with known usage where available, not semantic mistakes. Their raw output is archived but not replayed as a completed response; retries retain prior completed history and the same scalar feedback policy. HTTP/transport failures are separately censored. No server-side output schema is imposed. Answers are graded as complete symbol sets, allowing explanations and Markdown.
