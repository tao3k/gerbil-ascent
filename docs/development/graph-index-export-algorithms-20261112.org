This audit follows ASCENT from source and paper analysis through native
implementation, formal checks, and benchmark qualification. Each study
retains its original source revisions, conditions, and observed results.
Gerbil Scheme supplies the language, standard library, and =gerbil=
commands. Gambit supplies the VM, allocator, and collector. SDK in an
experiment receipt refers to the pinned =gerbil-bazel= release archive.

* Checkpoint scope

This revision publishes the Scheme weighted UF changes, native weighted
benchmark entry, and Lean and Org studies. Some experiments below used
additional local source changes or a privately linked Gambit runtime.
Those receipts identify their own inputs and remain separate from this
revision's verification. The published toolchain pin remains the
one inherited from PR #1. The full 235-case matrix and repeatable strict
100 ms scale acceptance remain open on a publishable build.
