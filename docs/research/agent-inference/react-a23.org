* Design assessment

The model can choose another tool call after a Library observation, but
=gerbil-ascent= should not own the Agent loop.  The Library offers a
stable result for an exact program/snapshot and a typed diagnostic or
bounded explanation.  The caller decides whether to search, revise a
rule, or ask a user.  ReAct helps justify the deployment-time loop;
it does not make a natural-language reasoning trace a verified witness.

* Discriminator

Freeze a question, source revisions and candidate-rule proposals.
Compare a one-call answer with a bounded inspect/execute/explain loop.
Track complete facts, source support, unsupported conclusions, tool
calls, token cost and latency.  Keep the model's narrative separate
from the Library's rule witness.
