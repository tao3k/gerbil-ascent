#+TITLE: Frozen membership routing and delta queries

* Production ownership and expression flow
Frozen rectangle views already publish endpoint and prefix routing. Membership
now reuses that routing to narrow descriptors and computes row width once per
query. A private =rectangle-contains?= checks arity, prefix and both member owners;
a shared endpoint value in a different group never proves membership.

One or two descriptors retain direct scanning: three coordinate hash probes,
bucket cost folds and candidate gathering cost more than this short scan.
Larger indexed views capture their full-coordinate ordinal list once. Views
with mixed arities take a bounded prefix and still check descriptor arity; rows
wider than the routing vector return false rather than raising an index error.
The original scan remains available to unindexed views. Difference membership
inherits the same path through its newer/older view owners. No public API,
Build.ss entry point, runtime option or test hook was added to production.

Gerbil SDK 1cfb032 =src/gerbil/core/sugar.ss:1022-1051= expands =cut= to a hygienic
partial lambda; the candidate predicate uses that existing expression form.
The implementation separates routing admission from the named exact ownership
predicate, following existing native hash dispatch and compact expression
composition rather than introducing another extensible receiver hierarchy.

* Matched native contract
=reference.ss= is exactly =91f8e042ed9b1e73499620d96571489e9f5deca5:core/relation-view.ss=.
Both implementations compile symmetrically. Fifty alternating pairs measure
publication of older and newer cuts, construction of their delta and membership
of each request in all three views. An independent direct descriptor oracle
checks each result outside timing. Public ASP =make-benchmark-fixture= and
=benchmark-run/result= own the fixture contract and series gate.

Many groups and absent groups require >=20% CPU reduction and 35/50 paired wins.
Wide, tiny and empty controls allow 110% plus 20us. All allocations allow 110%
plus 4096 bytes. This run launches no concurrent build or test lane during
measurement; global machine isolation is not asserted. CPU/allocation receipts
measure this provider workflow, not whole-engine solves.

* Retained negative results
Unconditional routing on the wide two-descriptor control measured CPU
151 -> 173us and allocation 134960 -> 155792 bytes, failing the allocation gate.
Its raw receipt remains ignored in =wide-unconditional-failed.ss=. The final
small-descriptor scan avoids this routing work without relaxing the gate.

The initial native harness selected an optional-arity publisher through a local
function variable. Its generated Scheme called the production publisher even
for baseline rectangles, causing a nominal rectangle type mismatch. Explicit
old/new publisher branches corrected lane ownership; no compiler was rebuilt
or modified, and no performance result from the failed harness was admitted.
