=GERBIL_BUILD_CORES=12 GERBIL_PATH=<qualified-prefix> just strata-benchmark=
runs compiled old and new algorithms in one process with alternating order.
The recipe compiles current planning and the reference oracle into one
isolated output directory with identical optimizing settings.
The relaxation oracle is frozen from =74f0046bb6137b4fce22db5ae398b9812734c137=. Candidate source manifests
are saved beside each raw receipt. Both local runs passed the matched gate.
These receipts identify the SCC source state before subsequent row-binding
edits in =program/funs.ss=; the stratification algorithm is unchanged.

Each case has 1000 paired samples. The positive case repeats 32 calls
inside each sample to amortize clock resolution; reported values are per
call. Strict-chain samples contain one call. Exact minimum strata are
checked after every timed sample. All samples are retained in =receipts/=.
