* Library package

=python/pyproject.toml= defines =ascent-engine=. Its =ascent_engine= package
provides the public CFFI client, Library artifact building/admission, Datalog,
evidence, and trajectory APIs. Scheme owns query semantics, source admission,
execution and result ownership. Python transports inert values and calls those
public contracts.

See [[file:NATIVE.md][Native API]], [[file:DATALOG.md][Datalog]] and
[[file:REVIEW.md][Evidence review]]. A pure Python package wheel does not qualify
portable native binaries or the target's Gambit runtime.

* Independent downstream project

Research, provider IO, process supervision, formal orchestration and native
consumer qualification belong to [[file:../workbench/README.md][ASCENT Workbench]].
It has its own =pyproject.toml=, dependency declaration, CLI and test directories.
It imports =ascent_engine=; the Library does not depend on the workbench.

=python/tests/= contains binding unit tests. =workbench/tests/= contains the
application's unit tests. =workbench/engine_tests/= exercises the public Library
through real native consumer calls. Native Scheme tests remain under =t/=.
Historical research records and source snapshots retain their original hashes;
this project migration does not transfer their live-call authorization.

* Local development

#+begin_src console
python3 -m pip install -e ./python -e ./workbench
python3 -m unittest discover -s python/tests -v
ascent-workbench formal all
#+end_src

Build the native Library through its existing build entry and supply the
prepared Library explicitly to native consumers. Existing build, request and
qualification deadlines remain unchanged.

Compiled =.oN= publication retains the original generation name and uses hard
links when available. Permission denial fails explicitly; use the normal
authorized publisher rather than accepting a silently copied generation.
Actual cross-volume copies are recorded as copies, with all byte checks retained.
