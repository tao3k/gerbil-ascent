* ASCENT 核心与调用关系

- 规则前端是 RuleProgram / RuleSession / RuleResult、Engine.rules、Scheme rules/。
- 查询、固定点、关系代数、typed values、retained SourceSession、增量更新与撤回留在 ASCENT。
- 通用 provenance、source generation、依赖、缓存身份与适用条件留在 ASCENT。
- 通用程序验证位于 candidate/checked-program.ss，不迁成应用评审策略。
- 通用 EvidenceLifecycle、EvidenceCacheAdmission 形式模型仍留在 ASCENT；按语义归属划分，不按单词机械删除。
- 已移除无实际消费者的 provider-protocol Cargo feature；模型 provider 解析归 POO。
- Datalog 只执行一次真实 SourceSession，不暗中附带 EvidenceChain 的第二次执行和合成缓存计数。

POO 的 Runtime 包含并调用 gerbil_ascent::Engine，应用 owner 与生命周期计数由 POO 拥有。
没有复制求值器。Clue、Interaction、Trajectory 源码归各自现有模块，当前由一个 native crate
编译。既有 POO Case/函数仍是正常 Scheme API；内部 packet transport 不被提升为公共框架。
