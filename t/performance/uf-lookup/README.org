#+LANGUAGE: en

* Architecture and reference contract
The complete public query boundary currently creates a temporary row-stream,
collects an outer list, and copies that list with =reverse=. The candidate
routes =gerbil-ascent-trrel-uf-view-lookup= through the view materializer with
a native one-/three-argument contract. The same invocation-owned native list builder
serves ordinary visitor fallback exports and selected queries. Existing full
rectangle exporters retain their direct product builder. Visitors own detached
public tuples; the collector owns its outer spine. For self-component cuts whose left/right member axes are the same object,
left queries reuse the frozen right-owner descriptor plan with the orientation
bound at visitation. This removes repeated owner-map and sort work without
allocating another plan or changing arbitrary cut handling. No query cursor is stored in
a captured view. UF's existing argument admission runs before visiting any row.

Gerbil =std/list/list-builder.ss= provides a scoped head/tail owner and
=defrules= for append. Its documentation warns that continuation reentry shares
the builder: this refinement applies to the synchronous single-pass visitor
contract already used by public lookup, not arbitrary resumed continuations.
The model's forward append is extensional; it does not implement the native
constant-time tail mutation or prove Scheme pointers/GC behavior.

Lean proves ordered forward collection and exact filtered materialization.
A separate cons-cell law accounts for one removed outer spine: legacy storage
is n*(width+2), owned storage n*(width+1), excluding constant heads, payloads
and runtime metadata. For grouped three-column rows this predicts a 20% cell
reduction, not a VM byte or end-to-end performance theorem.

=OwnedLookup.qnt= executes six selectors, including empty, repeated conflicting,
reordered and missing keys; independent results can be mutated and the backing
storage retired. Invalid selector admission must leave the frozen cut stable.
Exporter substitution, order, empty-key, duplicate, shared-result, borrowed-source,
retirement and rejection mutants must fail. The weighted export model additionally checks
that self-axis selection can reuse the opposite axis, with a wrong-orientation
mutant. Lean makes the equal-axis prerequisite explicit; native identity guards
are stronger than the model's extensional equality. Python checks the actual Library API and ABI
against an independent closure oracle and the held cut's exact order.
