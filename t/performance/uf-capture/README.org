* Implementation contract
Only singleton source components with a nonempty compact successor set may
concatenate frozen right axes. The diagonal comes first, followed by the exact
compact birth order. Weighted source components retain their per-target
rectangles. Weighted targets contribute every captured member in its existing
order. Copies own only the new right spine; captured records retain no mutable
UF nodes, adjacency arrays or planning tables.

The view routing flow creates owner lookup tables inside one reader invocation.
A right-axis query over multiple owners uses an immutable ordered descriptor
plan captured once by the view constructor, including shared owners. Each
descriptor selects a repeated member only once, and repeated descriptors keep
their original occurrences. Other query shapes own a temporary lookup frame.
Every coordinate is bound to its first query constraint. Repeated conflicting
constraints still pass through exact matching. A one-owner hit retains the
existing constant-time path. Multi-owner hits are translated once to a table
keyed by the captured member-spine identity. Nested readers cannot reuse each
other's query tables. Uniform descriptor families may scan in capture order
when gathering and sorting k hits costs at least the n-descriptor scan; mixed
arities keep checked routing, including its existing column admission behavior.

Physical view units include copied member cells as well as descriptors. Their
sizes differ, so this count is not used as an allocation or speed claim. Dense
closures still require quadratic logical public row storage. This change
reduces frozen descriptor/routing construction and repeated query owner scans.

* Gerbil source learning
Gerbil =std/list/list.ss= =group-same= scopes owned list collectors and reverses
only completed owned spines. =std/struct/dag.ss= scopes visitation state to the
call and caches completed attributes separately. The freeze and reader flows
follow these ownership boundaries, without a persistent cursor or new public
configuration switch.

* Models established before qualification
=ProviderRectangles.singleton_capture_order= proves the ordered concatenation
law. =compact_capture_order/count/selection= prove the guarded complete
transformation, weighted cardinality and exact filtering for arbitrary member
lists. =conservative_selection= proves a complete candidate scan preserves
ordered accepted rows. Native metadata consistency and schema admission remain
separate refinement obligations.

=RectangleCompaction.qnt= constructs scalar and weighted axes, target chunks,
compact output, committed weighted count and two independent reader keys.
It includes retirement after capture. Five mutants force heavy-source merging,
reverse targets, alias retired source storage, charge descriptor count instead
of row mass, or share reader selection state. Reader plans are captured with the cut and
remain unchanged by source retirement. Each must fail its named law.
This model executes the compaction transformation; it does not merely choose
prewritten expected row lists. Existing lifetime and UF models remain separate.
