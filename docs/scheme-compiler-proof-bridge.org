* Stated claim

[[file:../packages/proofs/lean/LexicalLowering.lean][LexicalLowering]] supplies a typed expression calculus, lexical environments,
a distinct relational IR, its interpreter and a logical relation between
compiled values and source meanings. It proves lowering preservation for every
well-typed expression in its source/parameter/function/apply/union/join/project/
select/flatmap grammar. The target relational IR has no function or application
node. Mathematical arrow values stand for compiler closures and capture their
defining environment. They do not authorize runtime Scheme callbacks.

The theorem is universally quantified over related environments and all
realizing arguments, including function arguments and returned functions. It
does not compare closure identities or choose a finite list of observed inputs.
The row case establishes extensional equality of relation membership. This
is a formal normalization theorem for the specified kernel, not yet a theorem
that =program/higher-order.ss= implements it.

The finite native discriminator enumerates all 16 pairs of subsets of ={0,1}=.
One factory returns a closure over a captured input; that closure is reused for
each argument. Its body combines union, keyed join, equality selection,
projection and finite mapping. Expected rows are computed by direct membership:
retain the captured set, adding 1 precisely when both inputs contain 0. The
reference does not call the typed compiler or positive operator interpreter.
Existing function-valued fix, escaped-binder, finite-domain and rollback Cases
remain in the same native Suite.

* Monotonicity and finite domain boundary

=denotation_monotone= proves preservation of a type-indexed logical relation.
Relations use inclusion; arrows relate outputs for every pair of related
arguments. =closed_function_monotone= specializes it to ordinary relation-to-
relation functions, without assuming the conclusion as a compiler premise.
Higher-order arguments must themselves satisfy the logical relation. An opaque
nonmonotone host procedure does not become admissible by having an arrow label.

This calculus excludes fixed-point syntax from its expression grammar. Its
separate unrolling theorem preserves each finite iterate but does not establish
that an arbitrary iteration count is sufficient. Existing rank/leastness laws
must still be connected to the concrete finite signatures and feedback compiler.
The mathematical source/table predicates and column maps are frozen denotations,
not executable Scheme effect checks or a new public callback API.

The tuple representation =Fin width → Fin atoms= states an admitted finite
domain explicitly. =concatenate_left/right/parts= establish a bijective layout
between a pair of such tuples and their concatenation, including empty tuple
widths. It supports =join_tuple_encoding= over every encoded row. Encoding
actual immutable Scheme scalars into that finite universe is a remaining bridge;
the Lean lemma does not establish their runtime hash/equality implementation.

* Descriptor preflight and owned row snapshots

=program/operator.ss= now revalidates the entire exposed descriptor graph
before compilation, fragment emission or reference interpretation. The DFS
checks node kinds, child counts, natural arities, matching signatures, column
indices, finite scalar source/mapping rows and transformer parameter/body
signatures. A visiting node rejects a descriptor pointer cycle. Legitimate
feedback is a finite body graph referring to a parameter node; it is not a
pointer cycle. A shared checked node remains a valid DAG edge.

After structural validation, the root must have no free parameters. This
check precedes =free-parameters= recursion on an unvalidated graph and precedes
rule emission. Validation snapshots source and mapping row spines; emission
uses those owned snapshots, so later mutation through descriptor accessors
cannot change the generated program's rows. Reference interpretation uses a
fresh validated snapshot per call. This is a synchronous admission contract,
not a claim of atomic snapshot acquisition under concurrent mutation.

=packages/proofs/lean/DescriptorScope.lean= proves seven identity-scope laws.
For finite acyclic descriptor unfoldings, all free identities being bound is
equivalent to recursive lexical scope validity. Closed roots, binder capture,
distinct identities, context extension and a shared child escaping its binder
are covered. Natural keys denote descriptor identities, not source spelling.
This abstraction models the dependency spine (other operator children combine
free dependencies); it is not mechanized extraction of the complete native
validator, row typing, DFS color table or descriptor-to-typed-IR translation.

Native regressions mutate rows, inject an opaque procedure into selection,
replace a child with an incompatible arity, create a graph pointer cycle and
modify source/mapping rows after compilation. All relevant entry points must
reject malformed graphs; a generated program must retain the original owned
rows while a fresh reference observes the later valid descriptor values.

* Scoped recursive relation bridge

phase with separate =PositiveExpression= and =ScopedIR= syntaxes. Both have
intrinsically scoped, row-typed variables and explicit =feedback= binders.

elimination; it does not silently extend =LexicalLowering.Expression= with
unproved general higher-order recursion.

Fourteen proved statements establish environment monotonicity, monotonicity
of each positive feedback body, lowering preservation for arbitrary captured
environments, and least-fixed-point equality. Feedback denotes the
intersection of all pre-fixed relations. =accumulating_least= proves that
adding current rows to the body result leaves this least closure unchanged.
=completed_iteration_is_least= establishes exact closure when an iteration
from bottom is actually stationary. Exhausting an iteration or row budget is
not this premise, and no termination/finite-height claim is smuggled into it.

* Native budget arithmetic bridge

=program/finite-arithmetic.ss= now owns natural capped multiplication and
power; =higher-order.ss= calls these operations while traversing the shared
finite type formulas. The cap remains =expansion-limit + 1=, a caller-owned
normalization budget sentinel, not a language Generation limit. A result at
that sentinel rejects expansion; it is never accepted as the true height.

=packages/proofs/lean/CappedArithmetic.lean= proves:

- Capping either operand preserves the capped product, including zero.
- The accumulator recurrence computes =min cap (acc * base^exponent)=.
- Clipping initial inputs preserves that recurrence.
- Zero cap, zero/one base and saturated positive-base branches are sound.
- The public power result equals =min cap (base^exponent)= for every natural
  cap, base and exponent, including =0^0=.
- Clipping an exponent before a later power preserves its capped result;
  this is required when nested type cardinalities supply capped exponents.
- Structural induction preserves entire nested power/product expressions,
  including the relation/arrow cardinality and height formulas.

Native multiplication clips both operands before multiplication. Power clips
its factor and accumulator, and exits on zero, one or saturation; it neither
constructs the full exact power nor decrements an enormous one-base exponent.
Its remaining exponent decreases on every nonterminal iteration. The proof
recurrence and native loop share the multiplication step; the optimized exits
have separate proved equations. Native regression compares all 4,913 triples
=cap/base/exponent in 0..16= with independent unbounded integer products,
then checks huge exponents, nullary/empty types, budget rejection and actual
function-valued fixed-point results.

This bridge proves arithmetic, not the semantic sufficiency of the composite
type height, descriptor-to-intrinsic binding translation, recursive IR or
native delta execution. Those compiler obligations remain open. The
[[file:evidence/scheme-capped-arithmetic-20261004/receipt.json][structured receipt]] binds the checked source and qualification;
execution logs are excluded. The bound native artifact passed two focused
modules with 49 Cases and 24 model-task native preflight checks; all six Lean
files, both TLA models and both expected faults passed. This is not a rerun of
all native modules or a new model experiment.

* Finite signature interpretation and typed admission snapshots

The new =FiniteHeight.FiniteShape= development instantiates these premises

=rank_bounded=, =rank_mono=, =rank_strict= and =bottom_least= extend those laws

=a= is zero; an empty atom domain and positive arity has no tuples. Complete

supply conservative bounds for admitted monotone inhabitants. The step's
monotonicity remains a premise; constructing a native type is not its proof.

* Projection descriptor to one positive rule

=lower-operator-graph= in =program/operator.ss=. The exact implementation seams
are =fresh-variables=, =variable-atom= and the =project= case in the primitive
emitter. The input body pattern contains all distinct column variables in
order; the head pattern selects those variables by the checked column list.

The model uses =Fin arity= for variable identities, a finite assignment for
their values, and =evaluatePattern= for atom arguments. =bindRow= constructs
an assignment from a proper row with the declared length. Three bridge laws
prove complete body length, lookup and reconstruction. The emitted rule means
there exists an assignment whose instantiated body is an input row and whose
instantiated head is the output. The descriptor independently means selecting
the checked columns of an input row of the correct arity.

directions; =emitted_projection_iff_descriptor= records their equivalence.

This is a rule-level mathematical model closer to the emitted syntax than the
previous generic projection IR law. Actual Gerbil descriptor decoding,
=gensym= freshness and capture avoidance, symbol-to-variable identity mapping,

obligations. The optimized projected-join branch has two body atoms and is

* Shared-key projected join rule

=Lowering.ProjectedJoinRule= models =join-variables= and the optimized
=project= over =join= branch of =lower-operator-graph=. Left column identities
inhabit one finite variable bank. Non-key right identities inhabit a disjoint
bank; the right key is replaced by the left key identity. The head selects
from the concatenation of these two patterns, exactly as the emitter does.

Eight theorems establish the shared-key alias, equality of instantiated body
keys, reconstruction of a matching right row, head projection of instantiated
bodies, rule soundness, rule completeness, their equivalence, and equivalence
of the descriptor to the existing join-then-project relational IR. Completeness
constructs one assignment from the two input rows; key equality is necessary
to recover the right key. Soundness obtains key equality from variable sharing,
rather than assuming a separate runtime filter. The head can reorder/repeat
columns or select none; no head injectivity or nonempty projection is required.

This adds a rule-pattern account of the fusion used by the native compiler.
