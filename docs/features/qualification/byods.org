* Admission of differential evidence (2026-10-07)

A BYODS lattice/negative/aggregate comparison cannot distinguish a computation
mismatch from a failed byte stream if the process adapter loses the read error.
The 10,000-pair other-shard failure for 7abd3d6 demonstrated that diagnostic gap,
while the direct Scheme, BYODS, scale and formal gates passed.

The adapter now preserves typed errors/partial bytes and requires complete
independent pipe reads before decoding and row comparison. Lean owns ordered
chunk replay and terminal rejection; TLA owns exit/read/request interleavings
and four fault controls. This is an acceptance-path correction, not a new BYODS
algebra theorem or Rust runtime integration. The historical syscall cause is
unknown because its diagnostic was lost. The original graph truth and deadlines
are retained. See [[file:../../scheme-trrel-uf-design.org][the design]] and
[[file:../../evidence/scheme-provider-views-20261007/oracle-byte-admission.json][the receipt]].
