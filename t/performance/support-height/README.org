#+TITLE: Grounded support height dependency flow

* Production ownership

=candidate/support-height.ss= owns one height computation over verified private
support. It indexes premise IDs to rules, seeds source/candidate facts at zero
and empty rule bodies at one, then wakes dependent rules when a height improves.
Conjunction uses one plus the maximum premise height; alternatives keep the
minimum. Missing support has no height. A cycle cannot seed itself.

The dependency table, final rule records, labels and pending spine belong to
one invocation. The retained owner performs completeness checking, ordered root
publication and detached row copying. Every read after withdrawal rebuilds its
labels; compaction cannot retain an obsolete shortest support. User callbacks,
proof construction and independent certificate verification remain separate.

Gerbil =1cfb032= =compiler/optimize-base.ss:24-29= gives an optimizer invocation
its own identity tables. =core/more-sugar.ss:118-129= provides native =until= for
condition-driven iteration. Native =andmap= owns short-circuit premise admission;
Typed final records express rule state. These mechanisms remove repeated
whole-graph scan control without inventing a new public graph framework.

Initial dependency admission costs O(E+P) for edges and premise occurrences.
Further work is the sum of activated rule bodies: labels can improve more than
once, so no universal linear-time claim is made. The public height work counter
now charges edge/premise admission, queue events, activated edge/premise reads,
completeness and roots. Its numeric value can differ from the full-scan baseline.
The same explicit budget bounds the work and exhaustion publishes no table.
Withdrawal's existing DRed algorithm and work charging are preserved.

* Frozen complete consumer

=reference.ss= freezes =candidate/provenance-maintenance.ss= from

imports are redirected to the same current Candidate modules. All prior
maintenance, height, compaction and row-copy algorithms remain intact.

Each fixture creates a complete certificate and independently verifies it
before timing. Reversing the private copied support order preserves every edge
and premise while exercising dependencies against scan order. Setup uses
public positive proof production/verification, outside the interval. The
consumer includes a complete height read, compaction, another complete height
read, and detached root rows. Independent heights for node i are i+1.
The withdrawn arm removes one of two duplicate source occurrences before timing;
the surviving occurrence must preserve all chain heights.

The original 96-edge preparation exhausted the fixed proof budget and did not
produce a complete certificate. It was rejected before timing. The admitted
fixture uses 32 edges; the proof budget stays 100000. The failed native log is
retained. No performance result is admitted without complete proof and independent
truth checks.
