* Owner and semantic contract

[[file:../../../candidate/annotations.ss][candidate/annotations.ss]] adds numeric interpretation to the existing
complete positive grounded graph. Its private =positive-counts= result records
status, reason, detached query rows/counts and numeric work. Source and program
closure replay remains owned by =candidate/provenance-graph.ss=.

Distinct alternatives add; ordered body occurrences multiply; zero counts seed
synchronous rounds. Each round starts a fresh accumulator. Only an unchanged
complete round publishes. Exceeding count/work limits or an incomplete graph
returns no numeric rows. This keeps relational membership completion separate
from annotation completion. No infinity verdict, polynomial, weighted callback,
negative rule or aggregate annotation is implemented.
