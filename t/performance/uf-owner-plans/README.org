* Models and implementation correspondence

Lean =ProviderRectangles= proves that permutation-preserving owner partitioning
and ordinal restoration recover the original ordered occurrence list. Mapping
that list to stored payloads preserves representatives; gathered cardinality
is the sum of selected owner occurrence counts. A separate self-axis theorem
justifies route sharing only under per-descriptor axis equality. Native identity
equality is the stronger implementation condition. These proofs do not prove
native hash lookup or Gambit sorting: those correspondences remain explicit
native regression and independent-oracle obligations.

Quint =WeightedExport= models distinct logical values/representative tokens,
interleaved owner IDs and descriptor positions. Existing frozen publication,
query, lifetime and budget invariants remain. Four added faults cover forced
route sharing, lost repeated-owner occurrences, query-key substitution for a
stored representative, and reversed publication. Each must produce its named
TLC invariant counterexample with original exit 12; parser/init errors are
failures, not accepted counterexamples.
