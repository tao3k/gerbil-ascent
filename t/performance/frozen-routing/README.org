#+title: UF frozen publication and rectangle routing

* Source-backed construction contract

Gerbil =1cfb032= =compiler/optimize-call.ss:259= uses =using= after resolving
class provenance. =compiler/optimize-base.ss:63= keeps named class metadata
rather than re-deriving fields while emitting expressions. Here the owned UF
freeze phase captures a final private =frozen-members= record: detached rows
and committed SCC cardinality. Each source is selected once; each rectangle
uses captured counts rather than traversing member lists per arc. The returned
view retains detached member spines, never UF nodes or mutable reach tables.

Routing owns buckets and processes each bucket's entire member list before the
next bucket. Therefore a repeated equal member already registered for the
current bucket must be at the head of that value's hit list. A head identity
check preserves the first stored value and the original descriptor order while
avoiding scans of hits belonging to previous owners. Private final bucket
metadata is accessed through =using=. This relies on synchronous construction;
readers see the completed tables only.

* Matched workflow and gates

Baseline =645354b16f5b7ce109126c9642785aa69412e881=. Both complete production
owners are frozen in =reference-view.ss= and =reference-uf.ss=; the latter's
only baseline modification redirects its view import to the frozen owner.
Public ASP =make-benchmark-fixture= creates the fixture before measurement.
Each shape runs 50 alternating pairs on the same immutable source states.
Source insertion and independent complete-truth checking are outside timing.

The measured interval includes state freezing, full indexed/scan publication,
an overlapping endpoint query, a complete point key, count/units observation and
an absent membership query. Each lane preserves its own full-scan query order;
cross-lane selected fact sets agree despite independent table seeds.
Full exported facts are checked independently for uniqueness and closure before
sampling; owner structure observations remain unchanged after every pair.
The new unit Case checks 96 overlapping keys, duplicate equal members, original
stored identity, repeated constraints and all four visitor paths.

Fixed gates: grouped endpoint overlap requires <=80% baseline CPU and >=35 wins;
SCC DAG, cycle, scan, small and empty controls allow <=105% plus 20us. Allocation
counter budgets are <=110% plus 8192 bytes. ASP pair p95 is <=999ms. Allocation
uses =##get-bytes-allocated!= with a fixed buffer, not retained heap. Timing
processes run alone. No insertion, whole solve or multicore claim follows.
