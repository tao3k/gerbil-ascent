* Acceptance status

The application migration is implemented on the existing PR branches. Full
acceptance is incomplete. This document records implemented ownership and
source-bound results; it is not an implementation plan or a release approval.

ASCENT owns the generic rule and Logical Programming library: rules, queries,
retained sessions, incremental maintenance and derivation provenance. POO Flow
owns Evidence, Clue, Trajectory, Review, Domain and model interaction. The
migration introduces neither an application compatibility layer nor an
anti-repetition prompt. No model experiment was run as part of this migration.
