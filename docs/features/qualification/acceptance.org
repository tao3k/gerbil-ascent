Polonius field order requires explicit schema translation: raw
=loan_invalidated_at= has =(Point, Loan)= columns, while the naive solver uses
an internal loan/point index. Raw =subset_base= is =(Origin1, Origin2, Point)=;
our grouped transitive Provider uses its grouping ordinal separately. Reading
two fields correctly by arity alone does not establish either translation.
The pinned reference also excludes self-subsets from its published =subset=.
A transitive Provider can derive diagonal pairs from cycles, so full result
comparison must validate an explicit non-diagonal projection rather than
silently comparing only counts or error sets. These differences must be tested
before admitting a complete Scheme Polonius application.

Lean owns representation-independent rule, projection and lattice laws; Quint
owns actual worker/source publication and cancellation histories. Application
laws must connect to the admitted native descriptors and full outputs. Existing
protocol models can be reused for unchanged publication paths; adding another
copy of the same model does not close numeric convergence, parsing or complete
rule correspondence. Package 9 remains open for the other applications and
package 10 remains open for matched end-to-end benefits. MR/MRR is deferred.
