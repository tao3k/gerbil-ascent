* Shared flow and Gerbil source study

The frozen kernel is byte-identical to =64742af763486f37e4318ed26f83b8bec46e4906=.
Both kernels consume complete fresh-state input trajectories, sharing the same
relation-view implementation. This is a UF kernel comparison, not a comparison
of historical/current whole engines.

Gerbil =1cfb032= =std/struct/dag.ss:31-51= separates visiting state, completed
attributes and mutation lifetime. =std/list/list.ss:365-376= accumulates owned
bucket spines and reverses only those spines. =gerbil/runtime/util.ss:366=
constructs output directly in consumer order. These patterns guide the shared
admission/publication flow rather than adding a new public dispatch protocol.

One stable target mask now serves scalar publication as well as counting.
Budget admission finishes before constructing descriptors or changing graph
state. Dense count admission starts with selected-bit cardinality and adds
only multi-member root excess, cached once by word. Sparse sources subtract
selected existing neighbors and their implicit diagonal from one cached target
mass. Fresh all-singleton axes use their exact cardinality instead of summing
each root. Acyclic count axes borrow stable adjacency; SCC planning preserves
its separate ordered selection.

Admitted scalar publication enumerates only missing pairs. A singleton source
can share a concatenated immutable target-member spine; sources admitting the
whole target axis reuse that spine within one publication. Multi-member sources
keep separate target rectangles because merging those rectangles would change
row order. Dense forward commit reuses one reverse writer per source. Published
cuts retain persistent members or fully constructed private spines, never
mutable adjacency, planning masks or excess summaries. Physical descriptor
units decrease; semantic row multiplicity, count and order remain unchanged.

positive selected mass as cardinality plus excess, sparse partition subtraction,

omitted implicit self mass. Existing =ProviderViews= and =ReaderLifetime=

is bounded to that finite universe.
