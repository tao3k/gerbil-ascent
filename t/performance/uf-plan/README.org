#+title: Frozen UF query plan reuse and tiny selection initialization

* One query execution contract
The baseline is the exact =4fe5b12e6fc8248ebd79d18bd99611deb4cd926e=
core; =reference-relation-view.ss= retains its bytes. Both arms compile with
upstream Gerbil =std/make= into native executables through the existing study
runner. There is no Python timing loop or retained mutable query cache.

A composite uniform query checks all coordinate ranges before detecting a
conflict, binds repeated coordinates once with ordinary tail recursion, and
routes each bound coordinate once. Key-tail bindings distinguish a fixed =#f=
from an unbound slot and retain the first equality obligation.

Wide two-endpoint queries borrow the captured, strictly ordered endpoint plans.
Two private list cursors advance by descriptor ordinal; equal ordinals admit
one descriptor and its stored singleton values. This removes per-query owner
hash tables. The shared left/right plan requires the existing identity check
for self axes. Prefix-constrained queries keep the narrow bucket path; mixed
schemas and nonindexed views retain checked selection. One or two uniform descriptors
use a bounded ordered scan, borrowing singleton values through one captured
read-only route carrier. No binding vector or query record is allocated per
invocation; mixed-width cuts retain bucket routing.

This follows Gerbil =1cfb032= =compiler/optimize-base.ss= constructor-owned
analysis metadata, =std/cache.ss= private typed final carriers, and
=std/list/list-builder.ss= scoped collectors. The useful contract is ownership
of construction, immutable plans and invocation-local traversal. No new
public generic dispatch or cache lifecycle is needed.

* Models and implementation correspondence
Lean =ProviderRectangles= defines the same ordinal merge and proves soundness,
completeness under strict ordering, preserved strict ordering, and at most
=left.length + right.length= cursor iterations. Existing first-binding and
ordered acceptance proofs remain. These laws assume admitted frozen plans;
they do not prove the Scheme compiler or hash-table implementation.

Quint =WeightedExport= models bounded cursor merge over captured owner plans,
checks exact ordered intersection, and adds =merge-skip= and =merge-order=
faults to the existing conflict/owner/retirement/public-row mutants. Native
Tests cover partial overlap, duplicate conditions, fixed =#f= values, stored
object identity, invalid coordinates after conflicts, and nested readers.
Actual Python API/ABI compare held cuts to an independent closure after SCC
retirement and repeat reordered queries over nonidentical group axes.

* Fixed performance contract
Ten scenarios use 20 alternating CPU pairs and 20 ASP admissions, eight
complete consumers per sample, and five allocation pairs. Wide selectors
repeat both endpoint conditions eight times over 64 distinct 128-member
owners. Tiny repeated selection executes 4096 complete queries per consumer.
Wide and repeated-small CPU require ratio <=0.9 and at least 16/20 wins.
Wide, small and repeated-small allocation require ratio <=0.8, with *zero*
absolute allocation allowance. Grouped/reordered/conflict/single-axis/
nonindexed/capture controls retain <=1.1 CPU +20us, allocation <=1.1.

Every query is checked against independent ordered Cartesian rows outside
measurement; counts are checked in every measured sample. Capture is measured
separately to expose any construction cost. No captured index was added.
CPU uses natural GC. Ordinary scenarios retain bounded one-consumer allocation
intervals. The repeated-small adapter covers every one of the same 4096 keys
in four fixed 1024-key legs, measures the same query consumer in each leg, and
checks the aggregate result. Input-spine slicing and result assembly occur
outside counters, equally in both arms; every raw leg is retained in the log.
Collection occurs outside counters;
negative deltas still reject the run. This is total measured allocation, not
peak memory or proof that the SDK's counter is globally monotone.

The parent native study retains its 90-second budget. Existing =uf-query= and
=uf-membership= contracts remain separate, unchanged regression gates. Logs,
raw pairs, source hashes and structured receipts belong only in ignored
=.cache/ascent/uf-plan/=. Actual Library/package/API budgets remain 120/15/45
seconds, using machine-native compiler concurrency and the installed SDK.
