#+title: Matched checked row binding

=GERBIL_BUILD_CORES=12 GERBIL_PATH=<qualified-prefix> just binding-benchmark=
compiles both binders and evaluators with identical optimizing settings
into one isolated library. It compares frozen =74f0046= row binding
with current checked binding plans. Raw terms and the source term grammar
remain unchanged; only first variable occurrences skip an environment search.

Each case has 1000 alternating old/new pairs and 20 warmups. Binding
kernels repeat 128 calls per span and report per-call nanoseconds. The
16- and 32-column kernels require median nonregression and at least
900 strictly faster pairs. The two-column kernel and individual solves
require median nonregression. Result bindings, row order, and independent
expected rows are checked outside timing spans. All raw samples and
source hashes are retained in =receipts/=.

Both final local runs passed, with process exit 0 and final =OK=.
Their source manifests match the retained production and benchmark sources.

** Rejected experiments

The initial two-column, 16-repeat measurement tied at the timer resolution
and failed its original 900-win gate. =experiments/fresh-only-initial.sexp=
retains that result and its source manifest. Final kernels use 128 repeats
for timer resolution; the narrow shape is a nonregression control.

An exact built-in Set fast path bypassed identity wrapping and duplicate
width checks while preserving the extensible Provider path. Individual
projection solves failed the attempted 900-win gate: 854/1000 and 882/1000
in =experiments/identity-fastpath.sexp=. That exploratory raw receipt has
no retained matching benchmark-source manifest and is not qualification.
The subsequent eight-solve batch reached only 705/1000 wins for width 16
and timed out before completing width 32; the log and its then-current
source manifest are retained in =experiments/identity-batch.log=. The
Set fast path was reverted before the final measurements.

The unchanged =ascent-indexed-joins= SS check retained 1000 samples and
its 2 ms p95 limit. With the experimental Set fast path, correct rows
were produced but p95 was 28.703 ms, failing that gate. The complete
diagnostic is =experiments/indexed-ss.log=. No cause is attributed to
host load, GC, or the watchdog from this evidence. Final binding receipts
do not close that failure or claim complete SS qualification.
