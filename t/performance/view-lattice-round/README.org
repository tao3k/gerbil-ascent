#+title: Complete native view and lattice round qualification

* Source and publication ownership

The full evaluator and round workspace are frozen at
=d8d872c9ab4438783ba145abe38b011eaf89948d=. Only evaluator import locations
change. The reference evaluator imports its frozen workspace; other dependencies
are shared unchanged. Both engines use installed Gerbil =1cfb032= and the
same native library root. No upstream compiler is rebuilt.

Gerbil =src/std/struct/lru.ss:19-32,45-67= uses private final records and typed
=using= projections to express mutation of affected owners.
=src/gerbil/compiler/optimize-base.ss:334-340= creates private state only when
needed; =src/std/iter/macros.ss:289-297= provides native accumulator iteration;
=src/std/list/list-builder.ss:5-24= provides ordered collection syntax.
ASCENT extends its retained layout and invocation-owned write set to exact
native Set/hash, EqRel/hash, UF/hash and native lattice/hash key tables.
One factory fold records the required staging capabilities; absent view or
lattice consumers do not allocate their staging vectors. Single-relation and
custom-provider engines keep complete traversal and existing version semantics.

Reset visits retained nonempty deltas plus nonempty totals of the newly admitted
stratum. Commit visits old frontier members and actual writes in ascending
declaration order. A native view extension is recorded even when it emits no
new rows: extension makes the storage owner pending, and that owner must return
to ready after the entire round publishes successfully. Admission precedes
clearing the write set; failures retain the replay requirement. Effective
lattice keys enter the write set once while retaining existing join order.
Source view append registers its published frontier. Empty unchanged lanes
retain valid native version-owned indexes and view cuts.

Reset selection uses =with-list-builder= to combine old frontier members and
nonempty seed slots without copying a hash table. Stratum slot lists are unique;
membership in the retained frontier excludes duplicates. Sorting preserves
declaration order; only after all resets succeed is the retained frontier
rebuilt. No temporary hash owner is needed for this immutable selection list.

An invocation owns one slot-mark vector and a touched-slot list. Dense admitted
relation indices give constant-time deduplication without another hash receiver.
Publication still sorts touched destinations with the retained frontier. Success
clears only touched marks, then discards the write list; it never sweeps the mark
vector between rounds. The vector is allocated once per invocation, not per
round. The retained stratum/frontier owners remain separate from this workspace.

Every leg constructs and solves a complete engine with one worker, then consumes
all relation sizes and rows. Warm declarations and immutable analysis are
prepared outside clocks; cold includes their construction. Mathematical expected
results independently check UF reflexivity and star reachability, maximum
lattice joins and Set callback recursion. Sorting normalizes enumeration only.
