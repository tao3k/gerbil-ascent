* Implemented behavior

The existing =relational-program= and =relational-fragment= macros now lower
optional =role= and =domain= annotations through their existing constructors.
There is no new parser, evaluator, runtime compilation command or JSON transport.

| Contract | Actual owner | Behavior |
|----------+--------------+----------|
| Relation contribution roles | [[file:../../program/scheme-checked.ss][checked constructors]], [[file:../../program/scheme-language.ss][macros]] | Input accepts external facts; derived accepts heads; mixed accepts both. Updates additionally require an admitted source handle. |
| Source authority | [[file:../../program/scheme-snapshot.ss][snapshot]], [[file:../../program/scheme-session.ss][existing Session]] | Checked admission/opening rejects derived source handles and input-only heads; updates retain existing handle checks and rollback. |
| Finite domains | [[file:../../program/scheme-checked.ss][existing finite constructors]] | Macro annotations rebuild the same membership checks, including derived rows and replacements. Explicit false domains reject. |
| Diagnostic origin | [[file:../../program/scheme-admit.ss][existing admission report]] | Head/body reader locations accompany existing rule paths; role/origin violations have typed codes. |
| Metadata ownership | [[file:../../program/types.ss][existing declaration factory]] | Known factory shapes survive metadata-only views; arbitrary caller objects do not obtain a shape stamp. Every ordinary data/root validation remains current. |

Unannotated direct relations retain their existing mixed meaning, regardless
of whether initial rows are empty. Fragment sources remain mixed by default;
private relations default to derived. Explicit input-only declarations reject
rule heads after whole-program assembly, including imported fragment handles.
An explicit derived role in a source group conflicts with that group's handle
grant and rejects at admission. Trusted lower-level host evaluation does not
acquire checked-language guarantees from these annotations.

Locations are detached native reader data, not authenticated source claims.
The frozen SDK emits file/start/end vectors; two-field file/start reader values
are also preserved. Callback and cyclic-list origin payloads reject before
retention/traversal. Origin never supplies relation identity, a support key,
mutation authority or a reuse decision. Normalized diagnostic presentation,
macro ancestry and actual dependency-cycle paths remain separate work.

* Concrete model/source correspondence

=DslDeclarations= now contains ten laws. In addition to the original eight
permission, filtering, composition, domain and erasure laws, =decode_spelling=
and =compile_cases_exact= connect the finite role table to its executable
lookup. The actual checked constructors import =program/declaration-role.ss=,
which is emitted from that table. The same table emits Quint role predicates.
The exact-source checker includes this production file. RoleSource/RoleHead
mutation controls must produce state counterexamples, not initial-state errors.

The strict source comparison also follows extracted owners rather than old
facade file paths. Descriptor term/key binding and Rust import renderings are
changed in their Lean emitters and checked against the actual source. Mismatch
collection still rejects every differing source region; it merely reports all
mismatches in one invocation.

The datum visitor's specialized arithmetic lane retains the generic fallback
for negative, fractional, bignum and unbounded budgets. An independent frozen
reference tests cycles, sharing and budget boundaries. The capped exponent
implementation has an independent exact arithmetic grid and a huge-exponent
control. The certificate iterator compares callback/guard order with a native
reference. These are executable discriminators, not universal source proofs.

* Remaining obligations

The finite decision-table correspondence is established at its stated boundary.
Native symbol representation, macro expansion, host callbacks/getter order,
mutable snapshots, VM/GC/FFI behavior and wrapper admission are still external
premises. Exact emitted strings do not prove those premises.

Universal source refinement of the complete mutable index cache, full SCC,
Actor/Rayon message transformations, datum traversal arithmetic and capped
exponent implementation remains open. General typed operator inference,
fragment contracts, macro ancestry and detailed dependency-cycle diagnostics
also remain beyond this tranche. Model proofs and finite tests must not be
reported as closing them.

Cancellation, budget exhaustion, source replacement rollback and provenance
remain part of full semantic and runtime acceptance. Their limits and original
performance thresholds are unchanged. CI success alone does not establish a
speedup, a cold-build improvement or complete Scheme source refinement.
