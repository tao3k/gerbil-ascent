#+title: Initial compressed source publication and compiled routing

* Gerbil source and shared construction flow

Gerbil =1cfb032= =compiler/optimize-top.ss:259-262= traverses admitted identifier
and expression lists together with multi-list =for-each=. Its constructor
optimizer (=optimize-call.ss:390-415=) resolves metadata before expression
emission. Apply those patterns where our planner already supplies correspondence
and projection: =program/objects.ss:126-157= returns ordered columns and their
exact ordered key terms in one admitted indexed atom.

=program/view-state.ss= now traverses relation declarations and dense positions
together instead of using =list-ref= for each eligible relation. Routing consumes
atom slot 4's compiled key terms rather than projecting slot 1 again through
slot 2's columns. No per-atom captured projection predicate is needed. The
private =publish-source-cut!= owner binds journal-backed total and initial delta
to one name/generation/revision, shared by initial and routed publication.
Published exporter closures capture the frozen cut, never mutable routing state.

The admitted schema and relation list have matching lengths. Eligibility and
source property reads retain declaration order. Excluded relations are untouched;
an unbound variable outside the compiled key cannot enable routing. No new
Provider behavior, external dependency or environment control is introduced.

* Native paired interval

Baseline =86ad9ae3469565bea6229b71ef1d9197c6a82d63=. =reference.ss= is complete
baseline view-state; its only modification redirects the source-replay import.
Public ASP =make-benchmark-fixture= generated the fixture before measurement.
Six shapes run 50 alternating pairs. Fresh source-owner buffers and POO source
declarations are prepared outside timing. The timed interval initializes all
eligible source cuts, processes rule-driven routing, checks routing flags and
observes selected total/delta metadata and exports. Each pair compares exact
name/generation/revision/lane/count and exporter truth against an independent
expected shape. Source owners are empty here; populated exports and held cuts
are qualified separately in unit tests.

Fixed gates: many/sparse 4096-relation scenarios require CPU <=80% baseline and
>=35 wins. Bound/literal 4096-atom controls plus small/empty allow <=105% +20us.
Allocation is <=105% plus 4096 bytes. ASP pair p95 is <=999ms. Allocation uses
a fixed =##get-bytes-allocated!= buffer, not retained heap. Timed processes run
alone. Source admission, compilation, rule closure and whole solve are excluded.
