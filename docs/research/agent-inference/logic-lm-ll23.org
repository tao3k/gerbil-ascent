* Assessment for gerbil-ascent

A reusable Library can make the feedback loop model-neutral: inspect a
candidate Scheme relational program, return a precise error with the
faulty relation/rule/argument, and allow another candidate attempt.
The model belongs in the caller.  The fixed-point evaluator receives a
fully admitted candidate program for one run and never calls the LLM
inside recursive evaluation.  An explanation must identify rule and
source supports rather than ask a result interpreter to invent a
plausible story.

* Experiment

Record an Agent-like transcript with an arity error, a corrected rule,
and a later semantic counterexample.  Compare error-only feedback with
feedback that includes the declared schema and a minimal failing row.
Measure repair count and final complete facts.  The comparison tests
our API, not the paper's claimed accuracy on its datasets.
