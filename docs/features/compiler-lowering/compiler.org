* Stated claim

[[file:../../../packages/proofs/lean/LexicalLowering.lean][LexicalLowering]] supplies a typed expression calculus, lexical environments,
a distinct relational IR, its interpreter and a logical relation between
compiled values and source meanings. It proves lowering preservation for every
well-typed expression in its source/parameter/function/apply/union/join/project/
select/flatmap grammar. The target relational IR has no function or application
node. Mathematical arrow values stand for compiler closures and capture their
defining environment. They do not authorize runtime Scheme callbacks.

The theorem is universally quantified over related environments and all
realizing arguments, including function arguments and returned functions. It
does not compare closure identities or choose a finite list of observed inputs.
The row case establishes extensional equality of relation membership. This
is a formal normalization theorem for the specified kernel, not yet a theorem
that =program/higher-order.ss= implements it.

The finite native discriminator enumerates all 16 pairs of subsets of ={0,1}=.
One factory returns a closure over a captured input; that closure is reused for
each argument. Its body combines union, keyed join, equality selection,
projection and finite mapping. Expected rows are computed by direct membership:
retain the captured set, adding 1 precisely when both inputs contain 0. The
reference does not call the typed compiler or positive operator interpreter.
Existing function-valued fix, escaped-binder, finite-domain and rollback Cases
remain in the same native Suite.

* Descriptor preflight and owned row snapshots

=program/operator.ss= now revalidates the entire exposed descriptor graph
before compilation, fragment emission or reference interpretation. The DFS
checks node kinds, child counts, natural arities, matching signatures, column
indices, finite scalar source/mapping rows and transformer parameter/body
signatures. A visiting node rejects a descriptor pointer cycle. Legitimate
feedback is a finite body graph referring to a parameter node; it is not a
pointer cycle. A shared checked node remains a valid DAG edge.

After structural validation, the root must have no free parameters. This
check precedes =free-parameters= recursion on an unvalidated graph and precedes
rule emission. Validation snapshots source and mapping row spines; emission
uses those owned snapshots, so later mutation through descriptor accessors
cannot change the generated program's rows. Reference interpretation uses a
fresh validated snapshot per call. This is a synchronous admission contract,
not a claim of atomic snapshot acquisition under concurrent mutation.

=packages/proofs/lean/DescriptorScope.lean= proves seven identity-scope laws.
For finite acyclic descriptor unfoldings, all free identities being bound is
equivalent to recursive lexical scope validity. Closed roots, binder capture,
distinct identities, context extension and a shared child escaping its binder
are covered. Natural keys denote descriptor identities, not source spelling.
This abstraction models the dependency spine (other operator children combine
free dependencies); it is not mechanized extraction of the complete native
validator, row typing, DFS color table or descriptor-to-typed-IR translation.

Native regressions mutate rows, inject an opaque procedure into selection,
replace a child with an incompatible arity, create a graph pointer cycle and
modify source/mapping rows after compilation. All relevant entry points must
reject malformed graphs; a generated program must retain the original owned
rows while a fresh reference observes the later valid descriptor values.

markers and exit 0; eight Lean files, both lifecycle models and both expected

* Scoped recursive relation bridge

=packages/proofs/lean/RecursiveLowering.lean= adds a relation-only compiler
phase with separate =PositiveExpression= and =ScopedIR= syntaxes. Both have
intrinsically scoped, row-typed variables and explicit =feedback= binders.
Sources, union, heterogeneous join, projection, selection and frozen flatmap
tables coexist with nested feedback. This phase follows lexical function
elimination; it does not silently extend =LexicalLowering.Expression= with
unproved general higher-order recursion.

Fourteen proved statements establish environment monotonicity, monotonicity
of each positive feedback body, lowering preservation for arbitrary captured
environments, and least-fixed-point equality. Feedback denotes the
intersection of all pre-fixed relations. =accumulating_least= proves that
adding current rows to the body result leaves this least closure unchanged.
=completed_iteration_is_least= establishes exact closure when an iteration
from bottom is actually stationary. Exhausting an iteration or row budget is
not this premise, and no termination/finite-height claim is smuggled into it.

The native compiler now keys its memo first by descriptor identity, then by
the relation handles of every free parameter. Closed nodes use the empty
binding list. Every free parameter is resolved before cache lookup, so an
escaped child remains an error even after it was compiled in a valid scope.
The same open subgraph under the same bindings shares a compiled instance;
different transformer inputs or outer fixed-point bindings remain distinct.
This ownership applies to fix, apply and ordinary emission paths.

Native regressions independently enumerate closure rows and inspect emitted
structure: a shared recursive mapping produces one private mapping source,
while duplicated consumers remain present. Two separately constructed
applications to the same source share a pipeline; applications to different
sources retain separate pipelines and results. Existing nested fixed-point,
escaped-parameter, source-withdrawal and fragment cases remain acceptance gates.
This is structural reuse evidence, not a runtime speedup measurement.

* Finite signature interpretation and typed admission snapshots

F16 §5.3 Lemma 4 requires monotonicity, a least element and finite height.
The new =FiniteHeight.FiniteShape= development instantiates these premises
with nested finite pointwise tables. =indexed_rank_bounded=, =indexed_rank_mono= and =indexed_rank_strict= sum over every input index;
=rank_bounded=, =rank_mono=, =rank_strict= and =bottom_least= extend those laws
through nested tables. =full_height_least_fixed= proves full-height unrolling
is stationary and below every fixed point, assuming the step is monotone.

=enumerateTables= lists all finite tables, with both length and completeness
proved. Tuple enumeration has length =d^a=, including one empty tuple when
=a= is zero; an empty atom domain and positive arity has no tuples. Complete
nested-value enumeration has length =cardinality= and covers every value.
=arrow_encoding_injective= encodes a semantic function over all input values,
not observed arguments; equality of complete tables reflects function equality.
The enumeration is a proof construction, not a production allocation policy.

=FiniteSignature= mirrors the exact native formulas: relation cardinality
=2^(d^a)= / height =d^a=, arrow cardinality =card(B)^card(A)= / height
=card(A)*height(B)=. =shape_cardinality= and =shape_height= establish formula
correspondence, and =signature_height_least_fixed= proves height sufficiency
for the exhaustively represented signature semantics. Full function spaces
supply conservative bounds for admitted monotone inhabitants. The step's
monotonicity remains a premise; constructing a native type is not its proof.

The native compiler already had a scoped recursive validator. It now returns
owned canonical types and typed-term graphs and lowers that returned graph.
Domain duplicates are removed by the same finite relation type constructor;
source/mapping rows, vectors, projection lists and child lists are reconstructed.
The binder itself is checked even when unused in its body. A global descriptor
copy table preserves binder/node identity; scoped validation still checks every
term occurrence and its current bindings before returning a cached copy.
Snapshot acquisition is synchronous; concurrent mutation atomicity is not claimed.

Public =relational-type-height-expression= uses the same type shape/cycle/depth
admission. Per-invocation cardinality/height caches reuse validated type identity;
they hold no callback or cross-invocation state. Production capped arithmetic
and the independent actual normalization work counter remain in effect. A
resource rejection is not a theorem of semantic nontermination.

Native discriminators enumerate nine tiny signatures (0/1/2 atoms and 0/1/2
columns), check relation/arrow height against independently generated tuples
and subsets, analyze a 24-layer shared type graph, reject opaque/cyclic domains
and typed graph cycles/out-of-domain maps, and mutate domains/source/mapping
rows after compilation to check program ownership. Existing exact expansion
boundaries and lexical/nested fixed-point controls remain required.

Remaining bridge: native scalar equality and deduplication to =Fin= atom codes;
row lists to tuples; native descriptors and captured environments to the typed
signature/term semantics; actual lowering-step monotonicity and memo/rule/delta
execution correspondence. These obligations cannot be discharged by the new
height theorem or by finite native test samples alone.

* Scalar and row representation slice

=Ascent.RowRepresentation= in =FiniteHeight.lean= now gives an explicit list-row model:
=admitted= checks exact row length and domain membership; =tuples= enumerates
the list universe, and =encode= maps row membership to the existing Boolean
table of width =domain.length ^ arity=. The model's scalar constructors are
exact integers, Booleans, symbol identities and characters, matching the
categories admitted by =program/scheme-checked.ss=. Symbol identity is abstract;
it is not the symbol's displayed text.

The proved laws cover tuple enumeration length and admission completeness,
domain deduplication/reordering, extensional encoding, duplicate row elimination,
union, empty relations, nullary rows, empty positive-arity domains and relation
rank/height correspondence. Inclusion preserves rank; adding a genuinely new
admitted row strictly increases it. Duplicates cannot witness strict progress.
=admitted_encoding_faithful= requires every input
row to be admitted. An unchecked encoding observes only the declared universe;
it must never become a runtime mechanism for silently dropping invalid rows.

Native qualification adds six Cases: distinct mixed scalar categories with
duplicate domains/rows, rejection of inexact/mutable/opaque values, two fresh
symbols with the same printed name, empty/nullary relation outcomes, and source
occurrence/materialization budget boundaries, and retained source-only updates
with immutable prior results.
These exercise actual Gerbil membership, domain hashing, lowering and solve.
All expected complete rows are Scheme data, independent of the compiler.

The first native run exposed a concrete boundary mismatch: source initialization
deliberately retains duplicate occurrences, but typed compilation returned a
bare source as its set-valued result. Mixed duplicate rows returned eight rows
instead of four; two empty tuples returned two instead of one. That artifact
failed qualification (exit 1, no final OK) and is excluded.

=program/higher-order.ss= now wraps a lowered source root in an identity
projection, so the returned typed output handle names a derived set relation.
Source handles, occurrence rows and source budgets retain their meaning. This
also covers a parameter application or function bottom that lowers to a source.
Existing computed roots already produce derived set relations. Callers use the
returned output handle; it need not equal a source's name. The materialized
output consumes derived/output budget, and the new budget Case requires that
cost rather than hiding it. No performance gain follows from this repair.

The first integrated qualification then exposed the named Session constructor's
all-relations-as-sources restriction. The new derived output correctly was not
a source handle, so two existing retained Cases failed. Named Sessions now
retain the snapshot's declared source arities, just as fragment Sessions do;
all checked append/replacement/transaction paths use that whitelist. Derived
relations remain queryable and cannot be updated through their output handles.
The added retained Case checks rejected helper mutations, source insertion and
replacement, duplicate occurrence observations, set output and a frozen old
result. This constructor repair does not grant helper mutation authority.

The mathematical =eraseDups= uses lawful decidable equality. Its equivalence
to Gerbil's =delete-duplicates/hash= and table hashing is not a mechanized
toolchain theorem. The native Cases discriminate that boundary on concrete
inputs. A total native scalar decoder, full runtime equality/hash correspondence,
descriptor/capture interpretation and actual compiler-step preservation remain
open. This slice establishes the row interpretation laws required by those
later refinements, without certifying arbitrary Scheme objects or callbacks.

The next descriptor/rule bridge must also distinguish typed term domains from
compiled schema envelopes: derived relations currently use the collected scalar
pool, while original sources retain their specific domains. The existing domain
order Case records that pooled envelope. A rule-preservation proof must show
which produced rows inhabit each term's own type; merely passing the broader
compiled field predicate is insufficient. Checked retained updates use the
source-handle whitelist; direct use of the generic native engine is outside
that typed authority boundary.

The compiler also declares mapping/selection tables as source inputs. The
whitelist enforces declared mutation authority, rather than proving arbitrary
changes to those tables preserve the original typed term. Their per-column
domains and mutation contract belong to the remaining term/rule refinement.

* Stored head and finite key correspondence (2026-10-06)

=PositiveSlots.compileHead= lowers the admitted literal/bound head grammar.
=compiled_head_vector_refines= equates reading those stored actions with
sequencing ordinary finite-vector observations, preserving order, repeated
terms and literal false. Unbound variables and wildcard heads are outside this
grammar. =readHeadVector= separates missing cells and body-only fresh actions
from successful output; this model refusal is not a new native decoder.
=compiled_head_binding_refines= composes that stored reader directly with
ordinary declared-head observations under the represented environment.

=IndexedPositiveTraversal.compiled_vector_key_refines= transports the actual
selected compiled actions to finite vectors. Compiler-derived slot bounds and
=VectorRep= provide the read correspondence. The existing =KnownColumns=
premise remains essential: key evaluation precedes candidate matching, so a
fresh variable cannot be admitted merely because its dirty cell is readable.
Columns retain their declared order and multiplicity, including an empty key.

The existing native positive-plan suite now inspects actual compiler-produced
vectors and tagged action pairs. Six ordered column layouts cover empty,
singleton, repeated, increasing, decreasing and mixed selections. It checks
the dense extent, distinct body/head action roles, immutable duplicated heads,
the purity flag, false-valued keys and complete ordered emissions over two
dirty-frame traversals. The ordinary association-list key reader supplies
independent key truth. An unbound head variable makes direct compilation
unsupported. Wildcard head rejection belongs to source admission: the private
compiler assumes admitted descriptors and does not validate that contract.
