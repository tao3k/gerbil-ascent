* Assessment for the Library

A graph Agent need not receive the entire relation store each turn.
For a proposed query or path, the Library can return the longest
validated prefix, the unsatisfied atom, and a bounded list of schema
choices or rows that explain the blockage.  That is diagnostic data;
the Agent decides how to revise.  If a candidate rule is recursive,
we also need fixed-point counterexamples from [[file:datalogbench-db26.org][DB26]], which Readi
itself does not supply.

* Experiment

Ask for a three-hop path with a wrong middle relation.  Compare a
bare =no result= response to one that identifies the failing hop and
valid neighboring relations under the same source snapshot and
budget.  Count repair turns; check final paths against the complete
graph.  Treat a source-generation change as a new attempt.
