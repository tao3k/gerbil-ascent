* Native complete-compilation A/B

The ASP Scheme benchmark API executes 50 alternating baseline/candidate pairs
of full =gerbil-ascent-compile-positive-plan= calls and consumes each resulting
frame extent, action count and output count. Both checksums must equal the
independent input expectation. Input preparation lies outside measurement;
all plan construction and its allocation are included. GC occurs before each
measurement; process user/system CPU and allocated bytes are measured. No build
or qualification overlaps the timing lanes.

Before execution, fresh and selected layouts each require >=10% CPU improvement
and >=40 faster pairs. Controls allow 110% CPU + 20 microseconds. Allocation
allows 110% + 4096 bytes. Gates were not relaxed after measurement.

Fresh compilation improves CPU about 29.0% and allocation about 25.5%; selected
compilation improves CPU about 31.4% and allocation about 23.9%. All controls
pass. The mixed case is retained as a control result, not a predeclared target.
These are local complete positive-plan compilation measurements, not public
solve or traversal speedups. Logs, receipts and binaries remain under ignored
=.cache/ascent/parts-layout=.

* Semantic consumers

Qualification reuses existing callback, positive-plan and traversal suites.
They cover exact selected and oversupplying providers, projected duplicate
heads, false values, repeated variables, dirty frames, callback ordering,
first failures, checkpoints and detached emissions, alongside independent
finite graph results. No implementation-mirroring unit tests are introduced.

Final local qualification: three Suites, 42 completed Cases, final =OK= and
exit zero, including all 512 directed three-node reachability controls. The
source-loaded exact-selected coordinate pipeline also passed. Native policy
completed with 31 existing advisories and zero errors. Two build attempts were
rejected by the source-snapshot guard during concurrent session/withdrawal
edits; their logs are retained. The third build passed admission before the
native suites ran. These receipts establish local qualification, not remote
CI completion.
