* Production change

This is one execution-path change: compile complete supported positive rules
into immutable numeric slot plans, reuse those plans across engines, traverse
with an invocation-local frame, construct ordered index keys directly from
slots, and emit through the existing engine admission boundary. One-shot
engines also avoid allocating Session-only source-update and timeout closures.

The supported fragment consists of positive atoms with variable, literal and
wildcard terms and simple admitted heads. Any expression, pattern, guard,
binding, generator, aggregate or negation clause keeps the complete rule on
the general interpreter. Admission, storage expansion, lattice merge, budgets,
Provider callback ordering, semi-naive pivots and output order are preserved.
The cache uses weak rule identity keys and a mutex; no mutable execution frame
is shared. The original analysis vector layout remains unchanged.

* Matched complete-solve measurements

Each workload uses 20 warmups and 1000 alternating old/new complete solves.
Samples record time and Gambit process-statistics slot 7 cumulative allocated
bytes; this is not the latest-GC gauge. There is no forced GC between samples.
The same source, heap, runtime and expected results apply to both engines.
An allocation gate requires non-increasing median bytes on every workload;
primary workloads also require at least 900 strict paired byte wins.
A timing claim requires a lower median and at least 900 strict paired time wins.

* Reproduction

From the repository root, with the same pinned dependency environment:

#+begin_src sh
GERBIL_PATH=/private/tmp/ascent-test-scheduling-gerbil GERBIL_BUILD_CORES=12 \
  just test
GERBIL_PATH=/private/tmp/ascent-test-scheduling-gerbil GERBIL_BUILD_CORES=12 \
  ASCENT_POSITIVE_PLAN_RECEIPT=/private/tmp/positive-plan-repeat.sexp \
  just positive-plan-benchmark
#+end_src

The benchmark recipe holds the exclusive test lease, builds into
=.gerbil/positive-plan/lib=, applies bounded native timeouts, and rejects native
ERROR/overflow markers even when the process exits zero. Source hashes are
written next to the receipt. =qualified.sources= pins the committed production
and qualification sources; =repeat-matched.sexp.sources= pins measured sources.

To construct the public old engine in a separate source directory, copy
=gerbil.pkg= and =public-baseline-evaluate.ss= to its =program/evaluate.ss=,
then run =build-public-baseline.ss= with absolute =ASCENT_BASELINE_SRC=,
=ASCENT_BASELINE_LIB= and =ASCENT_BASELINE_BUILD_DEPS= paths. Prepend the resulting
lib to =GERBIL_LOADPATH= and verify the public evaluator's =find-library-module=
path before loading =baseline-nonpositive-scenario.ss=. Keep the same original
performance profile and heap fence. Do not infer successful resolution merely
from a successful build or process exit.
